# Vista aerea

Ilustrações geométricas do clube visto de cima: Guaíba com barco de remo ao pôr do sol, piscina com raias, quadra de tênis com sombra de fim de tarde, área verde com copas e espreguiçadeiras, salão de eventos com mesas redondas. SVG em 1200×900 (4:3), pensadas para recorte em 16:9, 4:5, 1:1 e 9:16 com `object-fit: cover`.

Use como linguagem gráfica (capas, vazios de conteúdo, redes) e como placeholder até a sessão de fotos com drone. Cores fixas, de imagem: não mudam com o tema. Sempre retas, sem moldura, com legenda na linha d'água (componente Imagem).
