# AntesDepois

Quatro trechos das páginas atuais ao lado da versão no novo sistema. Serve para apresentar a evolução à diretoria e ao marketing.

As imagens da coluna "Antes" estão no grupo de assets "Antes" e foram recortadas de capturas de tela do celular em novembro de 2026 (associado.gnu.com.br e gnu.com.br).

Pares:
1. Polaroide com tachinha → CartaoSede com foto aérea e linha d'água.
2. Cartões de rótulo → Dados + chips.
3. Texto centralizado com destaques em ciano → título curto + parágrafo alinhado à esquerda.
4. Formulário com placeholder como rótulo e consentimento pré-marcado → Formulario com rótulos visíveis e consentimento desmarcado.
