# WhatsApp

O atalho de WhatsApp continua, em um formato só para os dois sites.

**Classes:** `gnu-whatsapp` (pílula com texto) e `gnu-whatsapp--icone` (só o ícone, 52px). Fundo `whatsapp`, o verde sóbrio que o gnu.com.br já usa no "Associe-se por WhatsApp", com `sombra-cartao`.

**Comportamento:** no celular, o atalho começa como pílula e recolhe para o ícone depois da primeira rolagem. Fica a 16px das bordas e nunca cobre botões, campos ou texto: reserve 80px no fim da página.

**O que muda:** sai o balão verde grande que hoje cobre parte do conteúdo em todas as telas da página de associação.
