# Imagem

Moldura de fotografia com proporções fixas e a linha d'água: um fio branco que atravessa a foto a 78% da altura, onde pousam as legendas.

**Estrutura:** `figure.gnu-imagem` + proporção (`--16x9`, `--4x3`, `--4x5`, `--1x1`, `--9x16`) → `img` (object-fit: cover) → `figcaption.gnu-imagem__agua` com até dois `gnu-rotulo-p` (esquerda: o quê; direita: onde).

**O consumidor fornece:** a foto com `alt` descritivo e as duas legendas curtas.

**Direção de arte**
- Duas famílias de imagem: **vista aérea** (drone, de cima, geometria das raias, quadras e copas) e **retrato de uso** (sócios reais, luz natural, câmera na altura dos olhos, movimento permitido).
- Fim de tarde é a luz da marca: sombras longas, pele natural, sombras levemente frias.
- As ilustrações aéreas do grupo de assets "Vista aerea" servem como linguagem gráfica e como placeholder até a sessão de fotos.
- Nunca: banco de imagem genérico, vinheta escura, polaroide, tachinha, rotação, texto com textura de água, faixas finas de 4:1.
