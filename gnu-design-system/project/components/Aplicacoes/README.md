# Aplicacoes

Quatro telas de celular que mostram o sistema montado: página de associação, página de sede, comparação de títulos e um story para o Instagram.

Use como referência de composição, não como layout fechado. O que vale observar:
- **Associação:** hero em foto aérea, título com uma ênfase, um botão, e a faixa Hoje no clube logo abaixo, no lugar do texto genérico.
- **Sede:** foto reta com linha d'água, nome em display condensado, dois dados como prova e o resto em chips.
- **Títulos:** dois cartões comparáveis; só o recomendado em `noite`.
- **Story:** o × une esporte e lifestyle; a Raia fecha a peça. A pauta (clínica de beach tennis, sexta às 18h) é um exemplo.

Os números de temperatura e horário são exemplos. Os endereços e a lista de estruturas vêm do site atual.
