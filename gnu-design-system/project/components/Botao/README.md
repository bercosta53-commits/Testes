# Botao

Um único estilo de botão para os dois sites, no lugar dos quatro de hoje (azul do associado, azul-claro do institucional, verde em pílula, caixa alta em Open Sans).

**Classes:** `gnu-btn` + `gnu-btn--primario` (`acao`), `gnu-btn--contorno` (fio `azul`), `gnu-btn--link` (texto com sublinhado e seta) e, sobre `marinho` ou foto, `gnu-btn--claro`. Largura total no celular: `gnu-btn--bloco`.

**Mantido:** a caixa alta dos botões atuais. **Evoluído:** Raleway 700 a 12px com espaçamento de 0,16em, altura de 52px e cantos de 2px. Fica mais fino e mais caro.

**Rótulos:** curtos e diretos. "Quero ser associado" continua. "Quero consultar valores disponíveis" vira "Consultar valores". "Enviar formulário" vira "Quero ser associado".

**Regras:** um primário por bloco. O secundário é contorno ou link. Nunca dois primários lado a lado.
