# Fotografia

A fotografia é o que mais comunica o padrão do clube. A regra é mostrar a vida acontecendo: pessoas, convívio, mesa, fim de tarde. A estrutura (piscina, salão, quadra) aparece como cenário.

**Proporções:** 4:5 em retratos e no celular, 3:2 em cartões, 16:9 em vídeo. Cantos `raio-2` dentro do conteúdo, retos quando a foto sangra.

**Tratamento:** luz natural, cores fiéis, sombras abertas. Sem filtros, vinhetas ou textos aplicados.

As fotos da prévia são as que o site usa hoje, recortadas de capturas de tela em baixa resolução. Substitua pelos arquivos originais e complete com a pauta acima.
