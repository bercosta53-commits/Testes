# Comodidades

A lista do que cada sede oferece. Substitui as seis caixas brancas centralizadas, que pareciam botões e ocupavam uma tela inteira no celular.

**Estrutura:** `ul.gnu-comodidades` → `li` com ícone de traço fino (1,25px, em `azul`) e o texto em `corpo-p` 500. Fios de `linha` entre os itens. Duas colunas no desktop, uma no celular.

**Ícones:** desenho linear, 24px, cantos arredondados, sem preenchimento. Os da prévia seguem essa regra (talheres, taça, piscina, balanço, árvore, bola); para produção, use um conjunto completo como Lucide ou Phosphor (versão light) no mesmo traço.

**Regras:** os mesmos textos de hoje, com números em algarismos ("10 salões"). Até 8 itens. Sem cartões, sombras ou cores de fundo.
