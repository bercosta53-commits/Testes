# Cruzamento

O × dos remos cruzados do brasão, usado como conjunção entre dois mundos do clube.

**Uso:** dentro de um título display, `span.gnu-x` com o caractere × (U+00D7) em `remo`, peso 300, largura normal. Exemplos: "Treino × Pôr do sol", "Família × Performance", "1906 × 2026".

**Regras**
- Um por peça. Só em títulos de 36px ou mais (o `remo` sobre `noite` passa 3:1 apenas nesse tamanho).
- Os dois lados são concretos e curtos: até 3 palavras cada.
- Nunca no lugar de "e" em texto corrido, nunca como ícone de fechar.
