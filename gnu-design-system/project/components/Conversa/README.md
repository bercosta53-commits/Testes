# Conversa

Atalho flutuante para falar com a secretaria pelo WhatsApp, no lugar do balão verde que hoje cobre o conteúdo.

**Classe:** `gnu-conversa`, com ícone de balão em `agua`, título e `small` com o canal. Fundo `noite`, sombra `sombra-2`, raio `raio-boia`.

**O consumidor fornece:** o link do canal e o rótulo. Posição: canto inferior direito, 16px das bordas mais as áreas seguras do aparelho; no celular, recolhe para só o ícone (48×48) depois da primeira rolagem.

**Regras**
- Um canal por tela. O site institucional e a página de associação usam o mesmo componente.
- Não usar o logotipo verde do WhatsApp: o nome do canal escrito basta e mantém a paleta.
- Nunca sobrepor botões, campos ou texto: reserve 80px no fim da página.
- O número no exemplo é ilustrativo.
