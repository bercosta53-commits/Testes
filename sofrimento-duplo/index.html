      Como é calculado

      • Sofrimento duplo = P(clube cai) × P(candidato perde). Clube e eleição são tratados como independentes.
      • Derrotas esperadas = P(clube cai) + P(candidato perde), de 0 a 2. O ranking segue essa medida.
      • P(Lula vence) = 1 − P(Flávio vence). O risco de queda é o do modelo do ValorFinal dado o empate no Gre-Nal.

      Fontes

      • Datafolha, 2º turno (Diario de Pernambuco, 08/10/2026)
      • Resultado do 1º turno (O Povo, 05/10/2026)
      • Risco de rebaixamento no Gre-Nal (ValorFinal)

      Cores: azul do Grêmio, vermelho do Inter, vermelho do PT para Lula e amarelo do verde-amarelo para Flávio. O roxo marca o sofrimento duplo. Tudo é calculado no navegador.
